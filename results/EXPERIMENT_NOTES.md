# Experiment notes

These measurements were generated by the latest run of the project.

## Dataset and split

The dataset contains 732 monthly observations, from
January 1950 through December 2010.

The first 12 observations are needed to create the longest lag. After that,
576 rows were used for training and 144 rows
were held back for testing.

- Training period: January 1951 to
  December 1998
- Test period: January 1999 to
  December 2010

## Forecast methods

**Naive baseline:** the forecast for a month is the observed temperature from
the previous month.

**Ridge regression:** the model uses the previous 1, 2, 3, 6, 12
months of temperature observations, along with the calendar month represented
by sine and cosine features. The model is a `StandardScaler` and `Ridge`
regression pipeline.

## Test results

| Method | MAE (°C) | RMSE (°C) |
|---|---:|---:|
| Naive baseline | 0.9942 | 1.1717 |
| Ridge regression | 0.4184 | 0.5344 |

Ridge regression reduced MAE by 57.9% compared with the naive baseline on these test months.

## What the test means

This is a rolling one-month-ahead evaluation. The model is fitted once using
the training period. During testing, the actual value from an earlier test
month can be used as an input when forecasting the next month. This reflects
a setting where a new observation arrives each month.

The result is specific to this dataset, the selected test period, the chosen
features and the fixed Ridge setting. It does not show that this model will
work best on other regions, datasets or forecast horizons.
